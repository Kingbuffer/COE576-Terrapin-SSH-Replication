A short demonstration you can teach

Allow 2–3 minutes. Ask the audience to predict the result before choosing “Show outcome”. Use the handshake walkthrough for the matched attack.

1 · Establish normal behaviour

“With no injection or deletion, all twelve packets verify. EXT_INFO arrives.”

2 · Delete one packet without compensation

“The client expects packet three, but the next server packet is four. The authentication check fails.”

3 · Add one, remove one

“Watch client Rcv move ahead when IGNORE arrives. NEWKEYS preserves the offset. Deleting EXT_INFO lets the server catch up. The remaining eleven genuine packets verify.”

4 · Turn on strict KEX

“The unexpected IGNORE is rejected during the handshake. The connection never reaches the deletion step.”

5 · End with the lesson

“Valid packets do not guarantee a complete conversation. The transition into encryption must also be protected.”

Words to explain

Snd / Rcv
Next outgoing / expected incoming packet numbers. Compare server Snd with client Rcv for the attacked direction.
Inject / delete
Insert an extra handshake message / remove an initial encrypted packet.
Accepted
Every retained packet passes tag, framing and expected-payload checks.
Rejected
An unexpected handshake message or failed packet check stops the receiver.
Attack success
An accepted suffix after actual prefix deletion. Clean acceptance is not an attack.
EXT_INFO
An extension advertisement. Its loss is shown; a real feature downgrade is not measured.

What is implemented?

  • Original ChaCha20 with SSH's sequence-number nonce.
  • Separate encryption keys for length and body.
  • Poly1305 authentication over encrypted length and body.
  • Real tag verification, decryption and payload comparison.
  • Known packet boundaries and shared test keys.
  • Schematic handshake and reverse-direction request; no real server authentication or key exchange.

Reproducibility: xorshift32 supplies public teaching keys and padding from a seed. This differs from Python's random generator; bytes will differ from the original batch. This is educational code, not a production cryptographic library.
